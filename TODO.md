# confluence conventions
Propose defaults and ask for confirmation/overridings:
- Page creation policy:
  - 1 Page - 1 jira Ticket
  - Same name as the ticket, no Jira ID
  - sub-pages for sub-tasks/hierarchy
- Page header includes link to Jira. Use Card style
- Container page (Initiative/Epic/Story) has initial content tree from the page itself
- Add a short "Goal/Purpose Section summarizing the ticket, rather than adding only the research outcome
- Authoring with Author/Date just after the header
- Setup skill can create the template pages
- Specify default emojis, ask what to use (or nothing):
  - 🧭 Initiative
  - 🎯 Epic
  - 📖 Story
  - ☑️ Subtask with no research outcomes
  - 🔬 Subtask with research outcomes
  - 🧩 Subtask with synthesized, temporary outcomes
  - 🏁 Subtask with research deliverables
