CLAIM 2: MCP tools/list Supports Pagination
--------------------------------------------
Statement: The MCP `tools/list` request supports pagination through an optional cursor parameter in the request and a nextCursor field in the response.

Evidence Label: VERIFIED
Source: Official MCP Specification - Tools
Authority: Primary authoritative source

Evidence:
- Request schema includes: `"cursor": "optional-cursor-value"`
- Response schema includes: `"nextCursor": "next-page-cursor"`
- Enables clients to page through large tool lists

Scope: Optional feature; cursor parameter is not required for all requests


CLAIM 3: MCP Supports Dynamic Tool List Updates
------------------------------------------------
Statement: MCP servers can declare a `listChanged` capability to indicate whether they will emit notifications when the list of available tools changes.

Evidence Label: VERIFIED
Source: Official MCP Specification - Tools
Authority: Primary authoritative source

Evidence:
- Servers declare capability: `{ "tools": { "listChanged": true } }`
- Quote: "`listChanged` indicates whether the server will emit notifications when the list of available tools changes."
- Enables dynamic tool discovery without client restarts

Scope: Optional capability; servers choose whether to support notifications
