## Decision Rights

### Architecture Decisions
**Owner:** Senior Agent Systems Architect  
**Consulted:** Senior Engineers, PM  
**Informed:** Entire team  

### Implementation Decisions
**Owner:** Implementing engineer  
**Consulted:** Architect, peer engineers  
**Informed:** QA, relevant team members  

### Feature Prioritization
**Owner:** Product Manager  
**Consulted:** Architect, stakeholders  
**Informed:** Entire team  

### Release Decisions
**Owner:** Product Manager  
**Consulted:** Architect, QA  
**Informed:** Entire team, stakeholders  

### Quality Gates
**Owner:** QA Engineer  
**Consulted:** Implementing engineers  
**Informed:** PM, Architect

## Communication Cadence

### Daily
- Standup (15 min, all team members)
- Async updates in team channel

### Weekly
- Sprint planning (2 hours, biweekly)
- Tech review (1 hour, engineers + architect)
- Documentation review (30 min, writer + architect)

### Biweekly
- Stakeholder update (30 min, PM + architect)
- Retrospective (1 hour, all team members)

### As Needed
- Design reviews
- Code reviews
- Architecture discussions
- Pair programming sessions
- Integration troubleshooting

---

## Escalation Path

**Level 1:** Team member ↔ Team member (peer resolution)  
**Level 2:** Team member → Architect/PM (technical/product decisions)  
**Level 3:** Architect/PM → Stakeholders (major decisions, blockers)  

**Response Times:**
- Critical blocker: <2 hours
- High priority: <1 day
- Medium priority: <3 days
- Low priority: <1 week
