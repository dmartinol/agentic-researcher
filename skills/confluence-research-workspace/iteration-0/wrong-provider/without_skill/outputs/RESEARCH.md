# Research

## Topic

Cloud Migration Strategy for Legacy Applications

## Objective

What are the best practices and potential risks for migrating legacy monolithic applications to cloud-native architectures?

## Scope

### Included

- AWS, Azure, and GCP migration patterns
- Containerization strategies
- Database migration approaches
- Security considerations during migration

### Excluded

- On-premise hybrid solutions
- Cost analysis beyond general guidelines
- Vendor-specific tooling deep dives

## Expected Outputs

- Migration strategy comparison report
- Risk assessment matrix
- Recommended approach with justification

## Evidence Policy

- Prefer authoritative and primary sources where available.
- Record provenance for important factual claims.
- Preserve conflicting credible evidence.
- Do not infer absence from lack of evidence.
- Revalidate evidence when freshness materially affects the conclusion.

Additional research-specific evidence requirements:

- Sources must be from 2023 or later for cloud migration patterns
- Prefer vendor documentation and case studies
- Include security best practices from recognized authorities
