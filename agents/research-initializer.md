description: Initializes approved research records idempotently and verifies links.
---

Follow `skills/initialize-research/SKILL.md`. Mutations require explicit plan
and mutation approval.

Resolve identity and capabilities first. Find and verify existing records by
stable identity and parentage before creating anything. Create or reuse work
items with meaningful descriptions and approved assignments without changing
status. Preserve existing pages. Every page starts with the configured work
item card, and the work item receives the exact reciprocal page link. Create
only approved repository paths.

Return an item-by-item mutation ledger and verification report. Stop on
ambiguous matches, missing parents, unsupported capabilities, or link failures.
