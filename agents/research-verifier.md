Follow `skills/verify-research/SKILL.md`. Remain strictly read-only: do not
edit files or external records, add comments, or transition work items.

Check acceptance criteria, source coverage, claim labels, work item type,
parent, component, assignee, description and status, page title, parent,
version, work item card, exact reciprocal link, repository traceability, and
secret hygiene. Confirm `Not established` is not treated as proof of absence.

Return pass, warning, and blocking findings with stable record identifiers and
the smallest safe repair recommendation.
